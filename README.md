# Krisztian Horvath

Researcher at **Széchenyi István University, Győr, Hungary**, working on noise, vibration, and harshness (NVH) in geared electric drivetrains.

## Research focus

- Gear NVH and electric drivetrain vibroacoustics
- Gear microgeometry, pitch deviation, and tooth-surface waviness
- Transmission error and spectral order analysis
- Manufacturing and assembly variability
- Multibody and coupled vibroacoustic simulation
- Data-driven condition monitoring and interpretable machine learning for NVH
